# CI-20261118 — dependency audit blocked CI

## Summary and impact

Two real CI runs failed at `npm audit --audit-level=high`:
[PR 44200237032](https://github.com/w1iii/CoursePilot/actions/runs/44200237032)
and [main 44254094935](https://github.com/w1iii/CoursePilot/actions/runs/44254094935).
The security gate worked; subsequent lint/type/test/build checks were skipped.
No production outage, exploitation, release blocking policy enforcement, or user
data exposure is established by these records.

## Cause and contributors

Confirmed immediate cause: dependency graph failed the high-severity audit
threshold. Main log reported picomatch ReDoS advisory and 16 high-severity entries
including dependent packages; this does not imply 16 independent root flaws.
Exact dependency remediation commit and advisory-database changes were not
established. Later green runs show recovery of CI status, not its precise cause.

## Response and lessons

Observed response: CI stopped at audit. A later main revision passed.
No evidence establishes a production rollback or a manually bypassed gate.
Preserve audit enforcement and treat skipped steps as unverified.
